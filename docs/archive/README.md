# 历史文档归档

这里保存已经完成或不再作为当前开发入口的研究、计划、规格和验收记录。

- `research/`：按轮次记录的体验审计、v1.2、作品发布、质量工具和早期云端评估。
- `superpowers/`：已完成的规格、实施计划和交互验收。

归档文件保留决策依据和当时的原始证据。它们可能包含旧分支名、旧测试数量、旧地址和已解决的问题；查看当前状态时以根 README、`docs/development-context.md`、`docs/release-readiness.md`、`scripts/local/README.md` 和 `deploy/README.md` 为准。
