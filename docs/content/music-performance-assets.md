# 陈果 / GUOER 素材清单与替换说明

先完成网站，素材可逐项补充；以下尺寸是建议，不是必须重新拍摄的门槛。保留你的原始文件，网站使用优化后的副本。

| 优先级 | 素材 | 建议提供 | 当前替补 |
|---|---|---|---|
| 已有 | 陈果手写签名 | 已迁移，无需重交 | 已有 SVG，保留真实笔迹 |
| 已有 | 音乐与影像 | 已有《我也想辍学》《凌晨的雨》音视频、两集线条时光 | 继续调用已发布作品 |
| 高 | 主打歌曲选择 | 告诉我首页先放哪一首；可附希望开始试听的时间点 | 暂优先《凌晨的雨》，缺失则选第一首可播放音乐 |
| 高 | 正式音乐音频 | 每首独立文件，WAV/FLAC 原始母带或高质量 MP3/M4A；有完整混音即可 | 现有音轨可直接使用，无需等待新混音 |
| 高 | 单曲封面 | 每首一张，建议正方形 2000×2000 以上，无平台水印；无图也可给色彩/意象 | 原创抽象声纹封面，独立可替换 |
| 高 | 本人主视觉 | 2–4 张原图：正面/侧面/持乐器或演奏，半身到全身，清晰且背景不杂，长边约 2400px 以上 | 球体＋签名＋抽象光线；不使用陌生雕塑冒充本人 |
| 中 | 演奏/录音片段 | 3–6 段，每段约 8–20 秒；横版 1080p 优先，竖版也可；手部、乐器、表情、录音环境 | 已有影像封面及抽象舞台 |
| 中 | 歌曲基础信息 | 歌名、创作年份、本人角色、合作署名、可公开歌词；不确定的字段可空着 | 使用已发布标题与现有描述，不虚构署名 |
| 中 | 个人生活/创作照片 | 6–10 张，可含排练、现场、旅途、设备细节；原图即可 | 已有影像与作品美术 |
| 中 | 发布/联系链接 | Bilibili、网易云/QQ音乐/Spotify/Apple Music 等已有主页或歌曲链接；可公开合作邮箱 | 保留现有已配置平台与联系方式 |
| 低 | 多轨/分轨 | 鼓、Bass、人声、其他乐器的 stems；只在未来需要更细的互动编排时提供 | 本轮直接分析完整音轨，无需 stems |
| 低 | 演出信息/个人短介绍 | 真实日期、地点、海报；30–80 字自我介绍 | 暂不显示未提供的经历或演出 |
| 低 | 字标或视觉偏好 | 若已有 logo/字体/色彩方案可给源文件；也可提供喜欢的封面 | GUOER 字标、真实签名、深黑/暖白/酸绿舞台 |

可以分批给；最有价值的第一批是“1 首主打歌曲确认＋2 张本人照片＋2 张单曲封面”。现有音乐已足够验证完整播放与互动。

## 交付整理建议

```text
GUOER-assets/
  portrait/        本人照片
  music/歌名/      音频、封面、歌词与署名.txt
  performance/     演奏、录音短片
  moments/         日常与创作照片
  links.txt        平台主页、联系方式
```

文件名不必严格符合示例。不要把私密联系方式放入准备公开的资料中。

## 网站替换入口

- 已发布歌曲/视频：继续通过原有后台作品管理上传、选取媒体和发布；公开页面读取 works API。
- 演出视觉配置：`frontend/src/data/stage.ts` 集中设置主打曲、本人肖像和作品封面覆盖。
- 原创临时美术：`frontend/public/stage/`。可直接以正式封面路径替换配置；移除某首覆盖后会回到后台的作品封面。
- 签名：`frontend/public/signatures/chen-guo.svg` 与已有线条数据。无需重新描摹。

是否采用每张照片、主打曲、封面色彩均可后续调整，不要求重新开发页面。
