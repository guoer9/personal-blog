# Notion 资料库链接导入：设计稿

日期：2026-11-02
状态：已按用户确认进入实施
范围：本地开发；不部署、不提交、不操作云端

## 意图

管理员在博客后台粘贴 Notion 链接，检查后手动确认导入。目标库中所有可安全转换的活动页面进入独立的公开“资料库”，按 Notion 已有分类展示；需要保护或无法完整转换的页面隔离。后续更新也只在管理员点击“手动同步”时读取 Notion。

## 目标

- 仅处理截图所指的“日记和文档”库及该库内页面；不搜索、遍历或导入整个 Notion 工作区。
- 首次用数据库链接检查并导入整库；已绑定目标库后可粘贴单篇页面链接，只导入该库内的这一页。
- 管理后台先检查链接并显示库名、页面数量、分类概况和隔离数量；管理员明确点击导入后，所有安全页面公开。普通博客文章和公开资料库分区展示。
- 后续新增、修改、归档、删除都由后台手动触发同步；应用启动时不请求 Notion，不存在定时/后台 Notion 同步。
- 复用 Notion 的 Select/Multi-select 分类；若没有则显示“未分类”，不得凭空造分类。
- 把现有 Notion 映射文章迁入资料库并保留旧文章路径跳转；普通博客文章维持现状。
- 某页含高置信度凭据或无法安全转换时隔离该页并继续处理其他页；如果此前已公开，立即下架。整个数据库/数据源读取失败时不改变上一次成功的公开结果。

## 非目标与保护

- 不导入目标库以外内容，不访问 Notion MCP、不使用聊天中出现过的任何 token，也不修改 Notion 页面。
- Notion token 仅由服务器环境配置读取，不写数据库、浏览器、日志、文档或 Git；管理员页面只显示是否已配置，不显示 token。
- 用户在聊天中公开过 Notion 凭据；这些值不得用于真实请求。真实联调仅在用户撤销旧密钥、通过本地私密环境文件配置新密钥后进行。
- 只允许 HTTPS Notion 主机链接；将链接解析成 ID 后调用固定 Notion API 主机，不能向用户给出的任意 URL 发请求。
- 不公开 Notion 签名临时文件或其他无法稳定、安全转换的媒体；转换器不得静默丢弃正文块。
- 不安排 Notion 自动任务、不做云部署、不混入文件传输/存储、公开作品或私人 AI 功能。

## 方案比较

1. **继续同步到博客文章**：表面改动小，但日记、部署文档会污染文章流和搜索；不采用。
2. **独立公开资料库，复用受限读取和 Markdown 转换**：文章流保持不变，资料可按类别浏览，改动集中且符合用户目标；采用。
3. **先全部导入草稿、逐篇再发布**：隐私防护强，但和用户已明确的“所有页面立即公开”不同；不采用。高风险和失败页面仍必须隔离。

## 流程与实现决定

1. 管理员粘贴数据库链接并点“检查”。服务端验证域名、数据库标题恰为“日记和文档”、只读集成访问权限和数据源 schema；仅预览，不写入或公开。
2. 检查结果展示活动页面数量、可识别分类和隔离页数量/原因类别，不返回正文、token 或秘密值。管理员点“导入并公开”后，服务端重新读取和验证，避免信任浏览器预览数据。
3. 页面逐页转换与凭据扫描。单页问题隔离并继续；整个数据源查询/分页失败时整次同步不落库、不下架原内容。成功页面幂等写入独立资料实体；归档或删除的已知页下架。
4. 后续同步在后台显式点击，使用已验证的数据源；单篇链接必须验证其父数据源与已绑定库一致。切换目标库需管理员重新检查并确认。
5. 公开资料库提供分页、分类筛选、标题/正文检索、详情页；普通文章列表、文章搜索与分类不混入资料实体。旧 `/post/{slug}` 对应 Notion 页面时跳转到资料详情。

## 持久化/API边界

- `NotionSource` 单例保存已验证数据库/数据源 ID、名称与配置时间；不存 token。
- `NotionDocument` 保存 Notion page ID、公开 slug、旧文章 slug（可空）、标题、Markdown、分类数组、状态、Notion 编辑时间和本地同步时间；状态区分 `published`、`isolated`、`archived`。
- 手动管理员接口：状态、链接检查、确认导入/切换源、手动同步、单篇同步；全部须管理员认证。
- 公开接口只返回 `published` 文档；隔离原因仅后台可见且不得包含正文/凭据值。
- 采用当前官方 Notion API 的数据库和数据源接口；token 仍独立于来源链接。单轮只访问固定 API 主机。

## 验收标准

- 无效/非 HTTPS/非 Notion 链接、非目标数据库、无权访问、库外页面链接被拒绝；链接解析不会形成 SSRF。
- 检查阶段不写入公开数据；只有管理员确认后导入。
- 手动同步支持分页、幂等新增/更新、归档下架、单篇隔离、全源失败回滚。
- 资料库列表、分类、搜索和详情只展示公开安全页面；博客文章列表与搜索不受资料库内容污染。
- 历史 Notion 映射文章进入新资料库，普通文章不迁移，原 `/post/{slug}` 可跳转。
- 应用启动与后台空闲期间没有 Notion HTTP 请求；任何 Notion 读取只能由管理员的手动动作触发。
- 本地后端、前端测试通过；真实 Notion 导入因凭据在聊天中暴露，本阶段使用 MockTransport/mock API 验证。没有新密钥前不声称真实连接成功。
