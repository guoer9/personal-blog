# Personal Blog v1.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 发布一个可靠、快速、可访问的个人博客 v1.2：先封存阶段 1 审计与 DDW 最小结构证据，再把 Element Plus 移出公共首屏，并完成一个原创、可降级、可测量的自适应画质实验。

**Architecture:** 公共博客继续使用 Vue 3 + Vite + 原生滚动，DOM 负责内容与语义，Three.js 只负责首页装饰场景。Element Plus 改为在认证、后台和文章评论交互需要时异步安装；DDW 研究只覆盖“输入 → 场景状态 → 绘制”和“离屏/隐藏/卸载 → 资源释放”两条结构链，不移植参考站点资产或复杂 GPU 管线。

**Tech Stack:** Vue 3, TypeScript, Vite 7, Pinia, Vue Router, Axios, Element Plus, Three.js, Vitest, Python Playwright, FastAPI, pytest.

**Spec:** `docs/research/00-research-plan.md`, `docs/implementation/2026-10-31-lusion-motion.md`

## Global Constraints

- 本次只实现 v1.2 交付范围；不复制 Lusion 的素材、着色器、模型、音频或文案。
- 不创建研究目标，不设置 token budget，不自动重启已结束的夜间调度器。
- 公共首屏不得因 Element Plus、中文语言包和后台图标继续承担约 `1,067.83 kB`（gzip `353.17 kB`）的主 JS 成本。
- 公共主 JS gzip 必须 `≤ 230 kB`，公共全局 CSS gzip 必须 `≤ 20 kB`；首个生产构建阶段与最终 release 各测 3 次。
- 发布目标为 Slow 4G 冷缓存下三次采样中位数：LCP `≤ 2,500 ms`，INP candidate `≤ 200 ms`，没有新增超过 `200 ms` 的长任务。
- `liquidScene` gzip 增长必须 `≤ 5%`；不得增加公共主包体积。
- 不接受新增后处理、ping-pong 纹理模拟、远程素材、自动播放音频或远程字体。
- 不删除用户内容、后台能力、WebGL 静态后备、减少动态效果路径或现有键盘语义。
- 所有浏览器结论必须记录浏览器版本、视口、DPR、网络条件、缓存状态、测量时间和原始输出路径。
- 每个 Task 先产生可失败的测试或确定性浏览器基线，再做最小实现；Task 结束必须运行指定验证并提交。
- 浏览器证据与生成物写本地忽略目录 `output/playwright/v1.2-20261101/`；研究结论写 `docs/research/`。

## Review Focus

- 公共页面首次加载时不能下载 Element Plus 入口、完整 CSS、中文语言包或后台图标；热路径与后台路径都要测。
- 请求拦截器在 Element Plus 尚未安装时仍须给出可见错误，且不能造成“等待 UI 后 toast 消失”的竞态。
- 登录、注册、后台菜单、表单、上传、删除确认和消息提示必须在异步安装后功能完整，不能因组件注册时序出现空白或失焦。
- 文章 404 深链、接口失败、真实内容成功页、空结果和归档分页必须在桌面、移动、reduced-motion 下有稳定状态。
- 自适应画质只能改变装饰场景；不得增加抖动、误降档、离屏继续绘制、资源泄漏或 reduced-motion 下的下载。

## Execution Checkpoints

按四个检查点顺序执行；上一个检查点未留下可复查证据，不进入下一个。

1. **Research gate（Tasks 1–4）**：冻结基线与前 15 轮研究，补齐文章 404 深链和真实内容成功路径，完成阶段 1 性能基线。产出是可对照的提交、测试计数、三视口浏览器证据和性能原始数据。
2. **Delivery gate（Task 5）**：把 Element Plus 移出公共入口，增加包体积门禁，回归认证/后台。只有公共主 JS `≤ 230 kB` gzip、全局 CSS `≤ 20 kB` gzip 才继续。
3. **Experiment gate（Tasks 6–7）**：先完成输入到画面、资源释放两条 DDW 结构链，再做自适应画质单变量实验。实验失败就按回滚规则移除，不阻塞 v1.2 的其他交付。
4. **Release gate（Task 8）**：跑完整页面、后台、性能、生命周期和可访问性矩阵；所有结论必须带原始输出路径，最终记录只能写 PASS、PASS WITH RESIDUAL RISK 或 FAIL。

每个 Task 的提交必须只包含该 Task 的文件。发现跨任务缺陷时另开后续 Task，不把无关修复塞进当前提交。

**Interfaces:**
- Produces: `type QualityTier = 'high' | 'balanced' | 'low'`.
- Produces: `interface QualityState { tier: QualityTier; slowFrames: number; fastFrames: number }` and `resolveQualityState(state: Readonly<QualityState>, frameTimeEmaMs: number): QualityState` with directional hysteresis.
- Produces: `frameTimeEma(previous: number, sample: number, alpha?: number): number`, clamped to finite non-negative values.
