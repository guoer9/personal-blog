# v1.2 发布验收

## 本轮范围

- 日期：2026-11-01（Asia/Shanghai）。
- 分支：`codex/blog-v1.2`。
- 验收对象：Tasks 1–7 的实现、研究证据和回归矩阵。
- 浏览器：Playwright Chromium `141.0.7390.37`，无头模式。
- 公共矩阵视口：桌面 `1280 × 720`、移动 `390 × 844`；移动场景分别使用普通动态效果和 `prefers-reduced-motion: reduce`。

## 发布结论

**PASS WITH RESIDUAL RISK**

v1.2 的公共入口拆分、文章 404 深链、真实内容成功路径、DDW 输入与释放证据、自适应画质实验、认证后台回归和包体积门禁均有可复查证据。严格发布风险是公共主 JS gzip 相比 Task 5 基线多 `1 B`；它没有增加公共入口原始代码体积，但尚未达到计划中“严格零增长”的字节级要求，因此不把结论写成无条件 PASS。

- 指针和滚动输入标记变化，可见场景帧标记持续增长。

## 未验证项与接受风险

- 本地 Vite preview 和即时 API 固定夹具不能代表真实生产网络、后端延迟、CDN、缓存策略或服务器资源。
- 未在 Safari、Firefox、真实 iOS/Android 设备、低端 CPU/GPU 上复测。
- 未测量真实操作系统后台标签页的功耗、GPU 内存曲线或 WebGL context loss 后恢复。
- 未查看截图，因此没有给出完全的视觉无回归结论；视觉人工验收仍是发布前的独立动作。
- 性能数据中的 INP 是实验室交互候选值，不等同于真实用户 INP。
- 公共主 JS gzip 的 `+1 B` 尚未消除；若后续发布要求严格字节零增长，应先固定构建产物或回滚 Task 7 运行时代码，再重新验收。

## 回滚条件

- 公共主 JS gzip 超过 `230 kB`、全局 CSS gzip 超过 `20 kB`，或公共路线重新加载 Element Plus 资源。
- 登录、注册、后台菜单、上传、删除确认、退出登录任一功能失败。
- 自适应画质出现单帧抖动、主入口原始体积增长、`liquidScene` 增长超过 `5%`，或 reduced-motion、离屏、隐藏、WebGL 失败、卸载路径回归。
- 出现新的可访问性回归、横向溢出、后台空白或 WebGL 资源泄漏。
