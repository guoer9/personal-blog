# 公开写作与登录用户临时传输：设计与执行计划

日期：2026-11-01。沿用 `codex/blog-v1.2`。仅本地开发，不部署云端，不启动 AI 对话，不建立研究目标或预算。

> 现行契约（2026-11-07）：传输功能必须登录后使用。原稿中的“访客可上传”只保留为历史背景，不再是当前产品要求。

## 用户确认与基线

- 公开站点不出现控制台、后台管理、存储管理信息；后台保留直接访问入口。
- 登录用户可上传临时文件、分享取件码；完成后保留 **6 小时**，单文件上限 **10 GiB（10 × 1024³ 字节）**。界面明确字节口径。
- Notion 只有准确勾选 **发布到博客** 的文章允许自动公开。未标记、撤销标记、归档均不得公开。
- 基线导航在管理员登录时展示“控制台”；公开文章 API 随管理员身份包含草稿，必须隔离。
- 基线搜索仅整段子串匹配、按日期排序，没有多词或标签权重。
- Notion MCP 可搜索；尚未确认截图中“日记与文档”的数据库身份。搜索相关度不构成身份确认。

## 临时传输设计

不复用私人素材库或作品发布目录。独立数据卷、磁盘元数据与进程间文件锁，8 MiB 原始分片，浏览器逐片读取，不把 10 GiB 文件读入内存。默认总预占上限 50 GiB，按来源限制并发和创建速率。无公开文件列表。随机取件码、独立随机上传管理令牌，磁盘只存摘要；下载强制附件、禁止缓存与类型嗅探。所有传输接口先经过登录校验。

完成前不可取件；成功完成后保留 6 小时。每次访问检查过期。启动及每 60 秒清理过期文件、残片和元数据；停机期间无法物理删除，恢复时补清理。上传开始后 6 小时未完成也清理。暂停/刷新后重新选择同一文件续传，指纹校验防止误拼；已接收分片幂等重试。清理和写入共用锁。

### 接口合同：前缀 `/api/v1/transfers`

- `GET /config`：返回 `max_file_bytes, chunk_bytes, retention_seconds`。
- `POST /uploads`：输入 `filename,size,fingerprint`；返回 `upload_id,upload_token,code,chunk_bytes,expires_at`。取件码只保存在客户端，不写日志。
- 以下使用 `X-Upload-Token`：`GET /uploads/{id}` 返回 `received_bytes,size,status,expires_at`；`PUT /uploads/{id}/chunks/{index}` 原始分片；`POST /uploads/{id}/complete`；`DELETE /uploads/{id}`。
- `POST /lookup`：输入 `{code}`；仅完成且未过期返回 `filename,size,expires_at,download_url`。短效 URL 不含原取件码。
- `GET /download/{ticket}`：原生附件流与 Range，不经前端 Blob 拼装。

## 写作、搜索与 Notion

公开 `/posts`、`/posts/{slug}` 永远只返回已发布内容；草稿仅管理员接口。后台 Markdown 手写或导入后保存草稿/发布。公开列表展示标题、摘要、标签、日期；详情展示正文、封面、阅读进度。改标题保持固定链接。

搜索采用 NFKC 规范化、多词 AND、标签匹配、标题优先和稳定分页；阻止旧请求覆盖新查询，保留键盘焦点。首版不宣称语义 AI 搜索。

Notion 定时同步需要独立只读集成凭据和明确允许的数据源，不提取桌面 MCP 身份。后台配置状态、手动同步；配置完整才启动本地周期同步。页面 ID 幂等映射文章，完整读取后原子更新。仅 checkbox `发布到博客=true` 公开；取消勾选或归档下架。失败保持本轮前状态并报告，不发布半页。遇到不支持内容/私有临时媒体地址阻止该页自动公开并提示，避免残缺内容。未取得真实库权限/运行凭据时明确显示未连接。

## 执行与验证

- [ ] A：移除公开后台入口；匿名/管理员公开读一致；草稿隔离；提交成功立即可见；固定链接。
- [ ] B：传输服务、定时清理，先红后绿测试分片重试、续传、10 GiB 上限、配额、权限、过期物理删除。
- [ ] C：登录用户传输页面；浏览器上传→另一已登录上下文取件→散列一致；刷新续传、移动端、可访问性。
- [ ] D：相关性搜索与旧请求保护；保留现有焦点、返回、分页测试。
- [ ] E：Notion 数据源核对、同步、后台状态、配置说明；验证勾选/撤回/幂等/分页/失败原子性，无真实授权时仅模拟契约。
- [ ] F：回归、构建、真实本地流程、独立审查；下一份研究记录写入证据与限制。

重点复核：大文件内存有界；匿名预占有界；过期与下载竞态；私密日记不经搜索或公开 API 泄露；来源失败不误发布或批量删除。
