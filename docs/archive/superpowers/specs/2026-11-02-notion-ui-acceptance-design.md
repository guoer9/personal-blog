# Notion 管理与公开资料库界面

日期：2026-11-02。基于已确认的多连接设计，用户已要求实施并做真实导入与浏览器验收。

用户补充：日记和文档是工作空间，授权使用选定连接访问整个可访问工作空间及按需求修改页面。增加按连接浏览可访问目录和独立页面来源支持。目录读取不等于公开发布；导入仍明确选择范围。允许 Notion Search 目录接口，不再受旧设计“不搜索工作空间”约束。没有具体原文修改需求时不制造内容变更。

再次补充：用户要求后台输入连接名称、密钥添加其他工作区。这明确取代仅手工维护本地凭据文件的旧约束。新增管理员 POST /admin/notion/connections，验证后原子写入本地凭据目录，响应及客户端持久化均不含密钥。Compose 改为挂载可写私密目录以支持原子替换文件。网页表单提交完成即清空密钥。

格式要求：公开卡片保留图标、封面；正文使用经过校验的 Notion 内容块，保留富文本、空段落、列表、待办、引用、代码、折叠与表格结构。Notion 托管图片限量下载为私密本地快照，只经已发布文档的媒体接口提供。预览及下架状态不可访问图片，不保存临时签名 URL。暂不支持的内容块阻止不完整发布。

- 管理员只选择本地已配置的连接，不在网页输入 token。多个连接展示名称和可用状态。
- 数据库链接先检查并展示标题、页面数、可公开数、隔离数及原因；显式勾选确认后才导入。切换连接或链接立即作废旧预览，迟到请求不能恢复预览。
- 已注册来源独立展示连接及最近成功时间，支持手动同步和来源内单页检查、确认导入；无启动或定时 Notion 请求。
- 导入提示明确：所选数据库内通过检查的页面将公开。同步可能下架归档/隔离页面，失败保留旧快照。操作期间禁止重复提交。
- 公开 `/documents` 独立于博客，支持 URL 中保存关键词、精确分类、分页；分类为文本输入，避免把当前页分类误称为全部分类。
- `/documents/:slug` 展示安全 Markdown、分类与更新时间，支持错误重试及 404。Markdown 禁用原始 HTML，拒绝危险链接协议。
- 旧 `/post/:slug` 的 API 重定向结果转至资料详情，不加载博客评论。
- 保留原有视觉语言、移动端、键盘使用与公开页面轻量依赖边界。
- 验收使用本地 PostgreSQL、FastAPI、真实 Chrome；真实 Notion 仅使用用户新配置的 token 和指定链接。无凭据时明确记录尚未验收，不把模拟数据当真实导入。
